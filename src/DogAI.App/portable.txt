This file makes DOG.ai portable.

While it sits next to DOG.ai.exe (or one folder above the app folder, as in a normal install), everything DOG.ai keeps stays inside this folder:
  data\    chats, characters, stories, documents, settings, logs, the model engine, scratch files
  models\  downloaded models and voice models
  app\     the program itself (replaced when you update)

Nothing is written to your user profile or anywhere else on the PC. Move or copy the whole folder freely;
saved paths follow it. To update DOG.ai, replace the app folder (and DOG.ai.exe): data\ and models\ are kept.
Start DOG.ai with DOG.ai.exe in this folder.

Delete this file to make DOG.ai keep its data in %LOCALAPPDATA%\DOG.ai instead.
